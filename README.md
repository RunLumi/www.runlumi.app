# Lumi website

Bilingual Astro website for [runlumi.app](https://runlumi.app), deployed as an Astro SSR application on Cloudflare Workers.

## Routes

Public:

- `/` — English landing page, prerendered
- `/vi` — Vietnamese landing page, prerendered
- `/jobs` — public careers index
- `/jobs/[slug]` — role detail + application + work sample

Hiring admin:

- `/admin/jobs` — jobs
- `/admin/jobs/[id]` — role editor + application test builder
- `/admin/jobs/applications` — candidate pipeline
- `/admin/jobs/applications/[id]` — full application review, files, notes, history

## ATS architecture

- **Astro + Cloudflare Workers** — SSR for dynamic hiring pages; landing pages remain prerendered.
- **D1** — jobs, test questions, applications, answers, stages, notes and audit events.
- **R2** — private CVs and candidate-uploaded work samples. Candidate files never receive public R2 URLs.
- **Signed admin session** — HMAC-signed HttpOnly cookie using Worker secrets.
- **Optional Cloudflare Access** — recommended as a second layer in front of `/admin/jobs*` and `/api/admin/*`.

The public apply flow works without client JavaScript.

## First-time Cloudflare setup

Install dependencies:

```bash
npm install
```

Create the D1 database:

```bash
npx wrangler d1 create lumi-jobs
```

Copy the returned database UUID into `wrangler.jsonc` under `d1_databases[0].database_id`.

Create the private R2 bucket:

```bash
npx wrangler r2 bucket create lumi-job-files
```

Apply the schema:

```bash
npm run db:migrate
```

Set admin secrets:

```bash
npx wrangler secret put ADMIN_PASSWORD
npx wrangler secret put ADMIN_SESSION_SECRET
```

Use a long random value for `ADMIN_SESSION_SECRET`.

For local development, create `.dev.vars`:

```dotenv
ADMIN_PASSWORD=local-only-password
ADMIN_SESSION_SECRET=local-only-long-random-secret
```

Then apply local D1 migrations and run Astro:

```bash
npm run db:migrate:local
npm run dev
```

## Deploy

```bash
npm run deploy
```

The Worker entry point is generated by `@astrojs/cloudflare`. Static assets and the Worker deploy together.

## Admin security

The app has its own signed admin session so it can run without an external identity product.

For production, also protect the admin surfaces with Cloudflare Access:

- `/admin/jobs*`
- `/api/admin/*`

Allow only Lumi hiring-team identities. Do not protect public `/jobs*` or `/api/jobs/*`.

## Candidate files

- CV: PDF, DOC, DOCX, max 10 MB.
- Test upload: PDF, Office documents, text/Markdown/CSV, spreadsheet, presentation, images or ZIP, max 15 MB each.
- Total uploaded payload accepted by the application endpoint: max 30 MB.
- Files are stored in private R2 and downloaded only through an authenticated admin endpoint.
- Deleting an application removes both D1 records and R2 objects.
